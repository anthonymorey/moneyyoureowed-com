Representative process

From deduction list to a letter preview.

This sample avoids the source demo’s UK/TDS mismatch. It shows the US self-help workflow without inventing an outcome.

Sample only. It is not a prediction, legal conclusion, or evidence that a claim will succeed.

1. Choose a covered state

Select one of nine named rule sets or the generic “Other” fallback.

2. Enter tenancy facts

Add deposit amount, dates, itemization, inventory, and receipt status.

3. List each deduction

Describe the item, amount, landlord’s reason, estimated age, and evidence.

4. Review the rules-based output

The local engine displays the frozen rules it applied and an estimate—not a legal conclusion.

5. Build and verify the letter

Fill in contact/property details, generate the source letter text, then verify statutes, deadlines, amounts, and local procedure before sending.

Run the local example
